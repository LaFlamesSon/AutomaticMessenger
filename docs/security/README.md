# CaughtUp Security and Privacy Program

Owner: CaughtUp owner and operator  
Security and privacy contact: support@getcaughtup.io  
Effective date: August 10, 2026  
Review cycle: At least annually and after material product, provider, regulatory, or security changes

This directory contains the policies adopted for the CaughtUp service. They apply
to the website, Chrome extension, backend services, company endpoints, service
accounts, and third-party processors used to provide CaughtUp.

The policies are intentionally proportionate to a small owner-operated service.
They document current technical safeguards and repeatable operating procedures.
They do not claim an independent certification, a formally appointed Data
Protection Officer, or controls that have not been verified.
