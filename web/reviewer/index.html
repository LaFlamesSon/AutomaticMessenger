Reviewer credentials

Use the dedicated temporary CaughtUp/Google reviewer account delivered through TikTok Partner Center’s protected review form. The username and temporary password are provided only in that protected form and are never published on this page.

The TikTok Shop Creator authorization must use the TikTok-approved testing account. Do not use or request the owner’s personal TikTok password.

Install the extension

  1. Download and extract the CaughtUp review build from the secure URL in the protected review form.
  2. Open chrome://extensions in Google Chrome.
  3. Enable Developer mode.
  4. Select Load unpacked and choose the extracted CaughtUp extension folder.
  5. Pin CaughtUp from Chrome’s Extensions menu and open it.
  6. Sign in with the dedicated CaughtUp/Google reviewer account.

Recommended test flow

  1. Open Opportunities in the CaughtUp tab bar.
  2. Open the secondary Connections area.
  3. Select Connect TikTok. This begins a separate TikTok Shop Creator authorization; Google sign-in does not grant TikTok permission.
  4. Complete authorization with the TikTok-approved Creator testing account and return to CaughtUp.
  5. Refresh Opportunities and inspect available product cards.
  6. Open Today and inspect inbox and negotiation cards.
  7. Open Kits to inspect owned media-kit configuration.
  8. Open Settings and confirm the account is in Review mode with Auto-send disabled.
  9. Open one prepared Gmail draft. Confirm the reply is editable and the attachment can be replaced or removed, then cancel without sending.

Expected results

Opportunities

Eligible cards show product name, available commission information, marketplace or platform evidence only when the listing supplies it, a concise fit reason, and relevant media-kit context.

Today

Actionable email and negotiations appear by event time. Negotiations are visibly distinct and remain review-only.

Draft review

The live draft is re-read before review. The reviewer can edit bounded text and replace or remove one owned media kit without sending.

Connections

Google and TikTok Shop appear as independent authorization states. Connecting or disconnecting one does not imply the state of the other.

Known limitation

TikTok Creator access is pending. CaughtUp has achieved the Read Creator Affiliate Collaborations permission package, but development-stage Creator OAuth may still require TikTok beta/allowlist approval and a designated Creator testing account. Live Creator product search has not yet been verified. If authorization does not return to CaughtUp, please record the result and use the contact below; the rest of the review can continue without sending email.

CaughtUp’s current affiliate feed may include clearly labeled manual/private sources. It must not represent those records as live TikTok Shop API results.
